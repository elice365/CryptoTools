## 3. 기능 요구사항 (Functional Requirements)

### 3.1 공통 기능
- **실시간 처리**: 입력 변경 시 결과 즉시 반영(디바운스 옵션 제공)
- **복사 기능**: 결과 영역 Copy to clipboard 버튼
- **파일 입출력**: 파일 업로드(드래그 앤드 드롭/파일 선택), 결과 파일 다운로드
- **유효성 검증**: 키 길이, IV/Nonce 길이, 입력 포맷(HEX/Base64/UTF-8) 검증 및 가이드
- **에러 처리**: 사용자 친화적 메시지(원인/해결 가이드), 로깅은 클라이언트 로컬 범위
- **다국어**: 한국어/영어/일본어/러시아어/인도네시아어/중국어 전 UI 번역, 언어 스위처
- **테마**: 시스템 기본 값 따라가되 수동 토글 가능(다크/라이트)
- **반응형**: 모바일(≤640px), 태블릿(641–1024px), 데스크톱(>1024px)

### 3.2 Base64 도구
- **인코딩/디코딩**: 텍스트/바이너리 지원, URL-safe 옵션
- **이미지→Base64**: 이미지 미리보기, 품질/포맷(jpeg/png/webp) 선택, 최대 파일 크기 25MB
- **Base64→이미지**: 디코딩 후 미리보기/다운로드

### 3.3 해시 함수
- **알고리즘**: SHA-1/224/256/384/512, SHA-3(224/256/384/512), BLAKE2(b2s/b2b)
- **입력**: 텍스트/파일, 출력: HEX/Base64 선택
- **옵션**: 해시 스트리밍(대용량 파일 청크 처리), HMAC 모드(키 입력)

### 3.4 대칭키 암호
- **알고리즘**: AES(128/192/256), DES, 3DES, RC4, Rabbit, ChaCha20, Salsa20
- **모드/옵션**:
  - AES/DES/3DES: ECB, CBC, CFB, CTR, GCM 지원(알고리즘별 합당한 조합)
  - 스트림계열: RC4/Rabbit/ChaCha20/Salsa20는 Nonce/IV, 키 길이 검증
  - 패딩: PKCS#7/NoPadding(ECB/CBC/CFB/CTR), GCM은 AEAD(Additional Data) 지원
- **입력/출력 포맷**: UTF-8/HEX/Base64 선택, IV/Nonce/Tag 별도 표시
- **키 생성**: 랜덤 키/IV 생성 버튼, 포맷 변환 도우미

### 3.5 비대칭키 암호
- **RSA**: 키 길이(2048/3072/4096), OAEP(PSS 선택은 서명 기능일 때), 공개키/개인키 PEM 관리, 암·복호화, 서명/검증
- **ECC**: 곡선 선택(secp256r1, secp384r1, secp256k1 등), ECDH 키합의, ECDSA 서명/검증, ECIES 유사 암·복호화(가능 시)
- **ElGamal**: 키 생성, 암·복호화(라이브러리 기반 구현 가능 범위)

### 3.6 블록 암호 운용 모드
- ECB, CBC, CFB, CTR, GCM 선택 UI
- IV/Nonce 길이 안내, 재사용 경고(GCM/CTR 등)
- AAD 입력 및 Tag 검증(GCM)

### 3.7 고급 암호
- **Paillier(준동형)**: 키 생성(n, g), 암·복호화, 덧셈 준동형 데모(c1⊗c2 → 합)
- **BGV(FHE)**: 데모 수준(라이브러리 제공 시) 키 생성, 암·복호화, 간단한 덧셈/곱셈 예시
- **주의**: 브라우저 성능 한계로 연산 시간이 길 수 있음. 진행 상태 표시, 취소 버튼 제공.

### 3.8 후양자 암호
- **Kyber(KEM)**: 파라미터(Kyber512/768/1024), 키 생성, 인캡슐레이션/디캡슐레이션
- **Dilithium(서명)**: 파라미터(Dilithium2/3/5), 키 생성, 서명/검증
- **상태 표시**: WASM 초기화/로딩 스피너, 기기 성능 경고, 벤치마크 간단 표시

### 3.9 URL 유틸
- **URL 인코딩/디코딩**: 전체/부분 문자열 처리, 안전 문자 옵션

### 3.10 국제화
- **언어**: ko, en, ja, ru, id, zh
- **방식**: 번역 키 기반(JSON/TS), 플래그/언어명 선택 드롭다운, 라우팅 상태 유지
- **용어집**: 암호 용어 일관성(예: IV=초기화 벡터, Nonce=논스, Tag=인증 태그)

## 7. 보안 고려사항 (Security Considerations)

### 데이터 경계
- 모든 연산은 브라우저 내 처리. **서버 전송 금지**.
- 클립보드/다운로드는 사용자 명시 동작에 한함.

### 키/비밀 관리
- 기본적으로 메모리 내 휘발성. 페이지 새로고침 시 폐기.
- "세션 유지" 선택 제공 시, sessionStorage에 암호화 저장(기본값: 꺼짐)

### 알고리즘 가이드/경고
- 취약 알고리즘/모드(DES/ECB/RC4)는 "학습용/호환용" 배지와 경고 표시, 기본값 비추천
- IV/Nonce 재사용 경고, GCM 태그 검증 실패 시 명확 안내

### 라이브러리 감사
- 검증된 오픈소스 사용, 버전 고정, SRI/Integrity 체크(가능 시)

### 콘텐츠 보안 정책
- 엄격한 CSP, COOP/COEP로 WASM/Worker 격리 강화

### 프라이버시
- 분석 도구는 PII 미수집, 입력 데이터 마스킹/비저장

### 법적 고지
- 지역 규제 및 수출 규정 고지(정보 제공 목적), 사용 책임은 사용자에 있음

- 주요 플로우(입력→옵션→결과→복사/다운로드), 언어 전환 상태 유지

### 접근성
- 키보드 전 플로우 가능, 스크린리더 점검

### 호환성
- 주요 브라우저/OS 매트릭스에서 정상 동작

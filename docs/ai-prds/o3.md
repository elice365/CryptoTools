## 1. Executive Summary (사업 개요)

본 프로젝트는 사용자가 브라우저 상에서 안전하고 직관적으로 다양한 암호화·복호화·해시·부호화 기능을 이용할 수 있는 다국어(한국어, 영어, 일본어, 러시아어, 인도네시아어, 중국어) 지원 웹 서비스를 구축하는 것이다. 모든 연산은 클라이언트에서 수행하여 개인 정보 유출 위험을 최소화하며, 최신 프런트엔드 스택(Next.js 15.5.4 App Router, TypeScript, Tailwind CSS v4, Shadcn/ui)을 활용하여 반응형·접근성·고성능 UI/UX를 제공한다.

## 3. Functional Requirements (기능 요구 사항)

### 3.1 암호·해시 도구

#### 1. Base64
• 인코딩/디코딩 (텍스트, 이미지)
• 이미지 ↔ Base64 상호 변환 (PNG/JPEG 지원)

#### 2. 해시 함수
• SHA-224/1/3/256/384/512, BLAKE2 (b2s, b2b)

#### 3. 대칭키 암호
• AES(128/192/256, ECB/CBC/CFB/CTR/GCM)
• DES, 3DES, RC4, Rabbit, ChaCha20, Salsa20

#### 4. 비대칭키 암호
• RSA(1024–4096), ECC(P-256/384/521), ElGamal

#### 5. 고급·동형 암호
• Paillier, BGV (연산 제약 명시)

#### 6. PQC
• Kyber(KEM), Dilithium(Signature)

#### 7. URL 인코딩/디코딩

### 3.2 공통 UX
• 실시간 결과(입력 debounce ≤ 200ms)
• 복사/클리어 버튼, 파일 업로드(.txt/.png 등) & 다운로드
• 입력 길이·형식 검증 후 에러 토스트(Shadcn Toast)
• i18n 동적 전환(언어 드롭다운)
• 테마 토글(다크/라이트, 로컬스토리지)

### 3.3 비기능
• 100% 클라이언트 처리(Web Crypto API + WASM fallback)
• 반응형(모바일 ≥ 360px, 데스크톱 ≤ 2,560px)
• 접근성(ARIA, 키보드 네비) AA 등급

## 4. Technical Architecture (기술 아키텍처)

### 1. Front-end Framework
• Next.js 15.5.4 App Router (Pages 없음)
• Edge-runtime 불필요, 완전 CSR

### 2. TypeScript Strict Mode
• noImplicitAny, strictNullChecks

### 3. Styling
• Tailwind CSS v4 (JIT)
• Shadcn/ui 컴포넌트 커스텀(Modal, Accordion, Tabs)

• Web Crypto API 기본
• asmcrypto.js / tweetnacl.js / wasm-blake2 예비

### 5. Internationalization
• next-intl + JSON locale dictionaries
• 플래그 아이콘 & 자동 브라우저 로캘 감지

### 6. State Management
• React Context + useReducer (lightweight)
• No Redux 필요

### 7. Build & Deployment
• Vercel / Netlify Static Export → CDN
• CSP 및 SRI 적용

### 8. Testing
• vitest + @testing-library/react (단위/UI)
• playwright(e2e, 모바일/데스크톱 뷰포트)

• **Header**: 로고, 언어·테마 토글, GitHub 링크

• **InputArea**: Shadcn Textarea (auto-resize) + file-drop zone
• **OutputArea**: Syntax-highlight(CodeBlock) + Copy button
• **OptionPanel**: Key/IV/Mode 셀렉터, 파라미터 유효성 실시간 표시
• **Toast**: 최대 3개, 4초 자동 hide

### 3. Color & Typography
• Tailwind gray-slate palette, accent #3b82f6
• Dark mode: bg-slate-900 / text-slate-100
• Pretendard KR + Inter(Latin) font stack

### 4. Animation
• Tailwind transition-opacity 150ms; no heavy motion for accessibility

### 5. Accessibility
• 모든 컨트롤 tabindex 순서 지정
• 색 대비 WCAG AA 이상 (4.5:1)

## 6. Security Considerations (보안 설계)

• 모든 연산 클라이언트 내 처리 → 서버 무상태
• HTTPS만 허용(HSTS preload)
• Content Security Policy: default-src 'self'; object-src 'none'
• Service Worker 미사용(캐시 민감 데이터 방지)
• Clipboard write 시 사용자 gesture 요구
• Large-key 연산(WebAssembly)에서 메모리 제로화(dispose)
• Bibliography 및 알고리즘 버전 명시, FIPS 140-3 준수 라이브러리 우선
• 면책 조항: "교육·테스트 목적, 생산 환경 사용 책임 사용자에게 있음"
